## Selected work

**Crowdsplit** — payment API for crowdfunding platforms<br>
Fiat↔token flows built over custodial wallet infrastructure. Carries **$15M/year** across a **3M+ user** public beta, mostly in LATAM.<br>
`Express` `Fireblocks` `DFNS` `Stripe` `Jest`

**Mavu** — microwork rewards inside Minipay<br>
Built with Opera and IDEO, launched to **6M users** across Africa. Wrote the vector-similarity matcher, in Solidity, that pairs workers with jobs.<br>
`Next.js` `Solidity` `Celo` `Hardhat`

**Co:Create** — a primitive for NFT application ecosystems<br>
Contracts and frontend for Autograph, the protocol's first prototype — part of the work behind a **$25M a16z-led seed**. Benchmarked 20 L1s and 11 L2s across 10 criteria to pick the chain.<br>
`Solidity` `Hardhat` `React` `Ethers.js`

**AttoEarth** — geospatial queries, on-chain<br>
A GIS engine for the EVM: a gas-optimized Quadtree in Solidity holding up to **2M points**, with range and point queries callable straight from a contract. Silver Award, Blockchain Olympiad Bangladesh.<br>
`Solidity` `IPFS` `Ceramic` `Node.js`
